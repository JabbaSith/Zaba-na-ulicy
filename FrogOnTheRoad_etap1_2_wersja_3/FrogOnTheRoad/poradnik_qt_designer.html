Qt Designer → C++ – poradnik do projektu Frog on the Road · Etap 1 → 2

Kod projektu jest już w pełni przygotowany na Qt Designer. Klasy MenuScreen i GameWindow mają dwa tryby pracy:

TrybKiedyCo robi
AKTUALNY Fallback Brak pliku .ui Buduje UI kodem C++ – aplikacja działa od razu
CEL Designer Po stworzeniu pliku .ui UI pochodzi z Designer – tylko trzy odkomentowania w kodzie
✅

Aplikacja kompiluje się i działa teraz, bez żadnych plików .ui. Plik .ui dodajecie kiedy chcecie – wymaga to tylko odkomentowania kilku linii.

1Jak to działa – mechanizm AUTOUIC

Gdy masz plik ui/menuscreen.ui, CMake automatycznie generuje ui_menuscreen.h w katalogu buildu. Ten plik zawiera klasę Ui::MenuScreen z metodą setupUi() tworzącą wszystkie widgety. 

// Co generuje AUTOUIC – nigdy nie edytujesz tego ręcznie
namespace Ui {
  class MenuScreen {
  public:
    QPushButton *btnPlayer;   // ← objectName z Designer
    QPushButton *btnAI;
    QLabel      *titleLabel;
    void setupUi(QWidget *widget);  // buduje UI
  };
}wygenerowane

Twoja klasa MenuScreen trzyma wskaźnik Ui::MenuScreen *ui i w konstruktorze wywołuje ui->setupUi(this). Potem dostęp do przycisków przez ui->btnPlayer.

3Qt Designer – tworzenie menuscreen.ui

Drzewo widgetów

QWidget objectName: MenuScreen
└── verticalLayout (QVBoxLayout, margins: 0, spacing: 20)
├── verticalSpacer (QSpacerItem, Expanding)
├── titleLabel (QLabel)
├── verticalSpacer_2 (QSpacerItem, Fixed 30px)
├── btnPlayer (QPushButton, minimumSize: 260×55)
├── btnAI (QPushButton, minimumSize: 260×55)
└── verticalSpacer_3 (QSpacerItem, Expanding)
  1. W Qt Creator: File → New File → Qt → Qt Designer Form, wybierz szablon Widget, zapisz jako ui/menuscreen.ui.
  2. Zaznacz cały widget (Ctrl+A) → kliknij prawym → Lay Out Vertically (lub Ctrl+L).
  3. Z panelu Widget Box przeciągnij Vertical Spacer na górę layoutu.
  4. Przeciągnij Label – nadaj mu objectName: titleLabel. Ustaw alignment: AlignCenter.
  5. Przeciągnij drugi Vertical Spacer, w Properties ustaw sizeType: Fixed, sizeHint height: 30.
  6. Przeciągnij Push Button – nadaj objectName: btnPlayer, tekst: ▶ Sterowanie gracza. Ustaw minimumSize: 260 × 55.
  7. Przeciągnij drugi Push Button – objectName: btnAI, tekst: 🤖 Trening AI. Ustaw minimumSize: 260 × 55.
  8. Przeciągnij ostatni Vertical Spacer na dół.

objectName – krytyczne

4Qt Designer – tworzenie gamewindow.ui

Drzewo widgetów

QMainWindow objectName: GameWindow
└── centralwidget (QWidget, automatycznie tworzony przez Qt)
└── verticalLayout (QVBoxLayout, margins: 0,0,0,0, spacing: 0)
├── scoreLabel (QLabel, minimumHeight: 30, maximumHeight: 30)
└── stackedWidget (QStackedWidget)
├── page (QWidget – strona 0, tu wstawimy MenuScreen z kodu)
└── page_2 (QWidget – strona 1)
└── gameView (QGraphicsView, minimumSize: 800×640)
  1. Utwórz New File → Qt Designer Form, szablon Main Window, zapisz jako ui/gamewindow.ui.
  2. Zaznacz centralwidget → Lay Out Vertically (Ctrl+L).
  3. Ustaw marginesy layoutu na 0: Properties → layoutContentsMargins → wszystkie na 0. Spacing → 0.
  4. Przeciągnij Label jako pierwszy element – objectName: scoreLabel. Tekst: Wynik: 0 | Rekord: 0. Ustaw minimumHeight: 30, maximumHeight: 30, alignment: AlignCenter.
  5. Przeciągnij Stacked Widget – objectName: stackedWidget. Powinien mieć dwie strony (page / page_2).
  6. Przejdź na stronę 1 (page_2) klikając strzałkę na górze stacka. Lay Out Vertically.
  7. Przeciągnij Graphics View na stronę page_2 – objectName: gameView. Ustaw minimumSize: 800 × 640.
  8. Zaznacz QMainWindow → Properties → geometry: szerokość 800, wysokość 670.
⚠️

Strona 0 stacka (page) zostawiamy pustą w Designer. MenuScreen jest wstawiany tam kodem w konstruktorze GameWindow: ui->stackedWidget->insertWidget(0, m_menu). Nie próbuj wstawiać MenuScreen do Designer – to widget tworzony w C++.

5Podłączenie do kodu C++ – dokładne instrukcje

ℹ️

Kod jest już przygotowany. Musisz tylko odkomentować zaznaczone linie i usunąć bloki oznaczone "TYMCZASOWY KOD". Poniżej masz dokładnie co i gdzie.

Krok A – include/menuscreen.h

Otwórz include/menuscreen.h. Znajdź i wykonaj dwie zmiany:

Zmiana 1 – odkomentuj include (linia ~16):

// PRZED:
// #include "ui_menuscreen.h"

// PO:
#include "ui_menuscreen.h"menuscreen.h

Zmiana 2 – odkomentuj member i usuń fallback (linia ~40):

// PRZED:
// Ui::MenuScreen *ui;
void buildFallbackUI();  // ← usuń tę linię

// PO:
Ui::MenuScreen *ui;menuscreen.h

Krok B – src/menuscreen.cpp

Otwórz src/menuscreen.cpp. Znajdź dwa bloki oznaczone komentarzami:

// Krok 1: odkomentuj cały blok "=== DESIGNER ===" (usuń /* i */)
// Krok 2: usuń cały blok "=== TYMCZASOWY KOD ===" (od MenuScreen::MenuScreen do końca buildFallbackUI)menuscreen.cpp

Po zmianach konstruktor powinien wyglądać tak:

MenuScreen::MenuScreen(AudioManager *audio, QWidget *parent)
    : QWidget(parent)
    , ui(new Ui::MenuScreen)
    , m_audio(audio)
{
    ui->setupUi(this);

    connect(ui->btnPlayer, &QPushButton::clicked,
            this, &MenuScreen::onPlayerModeClicked);
    connect(ui->btnAI, &QPushButton::clicked,
            this, &MenuScreen::onAIModeClicked);

    if (m_audio) m_audio->playMenuMusic();
}

MenuScreen::~MenuScreen() { delete ui; }menuscreen.cpp

Krok C – include/gamewindow.h

Zmiana 1 – odkomentuj include (linia ~20):

// PRZED:
// #include "ui_gamewindow.h"

// PO:
#include "ui_gamewindow.h"gamewindow.h

Zmiana 2 – odkomentuj member i usuń tymczasowe wskaźniki (linia ~52):

// PRZED:
// Ui::GameWindow *ui;
QStackedWidget *m_stack;        // ← usuń
QLabel         *m_scoreLabel;   // ← usuń
QGraphicsView  *m_gameView;     // ← usuń

// PO:
Ui::GameWindow *ui;gamewindow.h

Krok D – src/gamewindow.cpp

Odkomentuj blok === DESIGNER === i usuń === TYMCZASOWY KOD ===. Następnie w metodach showMenu(), showGame(), onGameOver(), onScoreUpdated() zamień trzy odwołania:

// showMenu() i showGame():
m_stack->setCurrentIndex(...)    →  ui->stackedWidget->setCurrentIndex(...)

// onGameOver() i onScoreUpdated():
m_scoreLabel->setText(...)       →  ui->scoreLabel->setText(...)gamewindow.cpp

6CMake – dwie linie do odkomentowania

Otwórz CMakeLists.txt. Znajdź sekcję UI_FILES i odkomentuj obie linie:

# PRZED:
set(UI_FILES
    # ui/gamewindow.ui
    # ui/menuscreen.ui
)

# PO:
set(UI_FILES
    ui/gamewindow.ui
    ui/menuscreen.ui
)CMakeLists.txt

Następnie w Qt Creator: Build → Run CMake (lub Ctrl+Shift+B).

✅

CMake ma już CMAKE_AUTOUIC ON i CMAKE_AUTOUIC_SEARCH_PATHS ${CMAKE_SOURCE_DIR}/ui – nie musisz nic więcej konfigurować. Po dodaniu pliku .ui do targetu CMake automatycznie wygeneruje ui_gamewindow.h i ui_menuscreen.h.

Częste błędy i rozwiązania

BłądPrzyczynaRozwiązanie
'ui_menuscreen.h' file not found Plik .ui nie jest w targecie CMake lub brak AUTOUIC ON Odkomentuj linie w UI_FILES w CMakeLists.txt → Run CMake
no member 'btnPlayer' in Ui::MenuScreen objectName w Designer to np. pushButton zamiast btnPlayer W Designer zaznacz przycisk → Properties → objectName → wpisz btnPlayer
Podwójne przyciski / pusty ekran Zostawiono stary kod fallback razem z Designer Upewnij się że blok TYMCZASOWY jest w całości usunięty
use of undeclared identifier 'ui' Zapomniano odkomentować Ui::MenuScreen *ui w nagłówku Krok A / C w checkliście
